# 印稿设计坊 · 篆刻矢量设计工具

浏览器里的印稿矢量设计与排版工具:从篆字到刻制尺寸一条线,全部本地处理,不上传任何素材。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 构建(含类型检查)
npm run smoke      # 核心几何冒烟测试
```

## 页面

| 页面 | 功能 |
| --- | --- |
| 印稿设计 | 真实毫米画布、毫米标尺随缩放联动、反字镜像(上石)、单字旋转/斜切/等比缩放并实时显示实际毫米尺寸、字距行距拖拽、朱文/白文一键切换、细朱/满白/圆角边框、种子化做旧与橡皮修补、边款(楷/隶)、SVG 矢量导出 |
| 篆字库 | 内置常用小篆字形;缺字可拼偏旁(左右/左中右/上下/上中下)或导入字形图自动描摹成矢量 |
| 章法模板 | 一字至多字印的回文、顺读等排法,选中自动套排当前印文 |
| 钤印预览 | 按作品幅面摆多方印,位置/转角/大小数值精确到 0.1mm,十字定位线与中心吸附,同一方印多次钤盖,印泥颜色 multiply 叠盖 |
| 作品管理 | 委托单分组、待确认/已刻制/已交付三档状态、客户与日期筛选排序、列表/卡片双视图、按月交付量统计 |

## 矢量内核

- 全部几何在**毫米坐标系**下进行,画布只是缩放视图,印面尺寸不走样。
- 篆字以「笔画中心线 + 线宽」存储,渲染时膨胀成轮廓多边形(圆头圆角),放多大都不糊。
- 朱文 = 字 ∪ 边框;白文 = 印面 − 字;做旧崩边与斑驳 = 沿边缘/内部按**种子随机**布点后做**矢量布尔差集**——同一种子每次残边完全一致;橡皮修掉/补回也是布尔运算,操作即数据。
- 布尔运算使用 `polygon-clipping`(Martinez 算法),无贴图、无位图特效。
- 导出 SVG 以 `mm` 为单位,可直接用于打印上石或激光刻绘。

## 数据

所有作品、委托单、自定义字形存在浏览器 `localStorage`(键 `seal-studio.v1`),素材不出本机。
